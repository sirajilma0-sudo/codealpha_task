# CodeAlpha Python Internship

This repository contains the Python internship tasks completed for CodeAlpha.

## Task 1 - Hangman Game
A simple text-based Hangman game where the player guesses a randomly selected word letter by letter.

### Features
- Random word selection
- Maximum 6 wrong guesses
- User-friendly console interface
- Win and lose conditions

## Task 2 - Stock Portfolio Tracker
A Python program that tracks stock investments and calculates the total portfolio value using predefined stock prices.

### Features
- Stores stock names and quantities
- Calculates investment value
- Displays total portfolio value

## Task 4 - Basic Chatbot
A simple rule-based chatbot that responds to user inputs using predefined responses.

### Features
- Interactive conversation
- Predefined responses
- Easy-to-understand Python logic

## Technologies Used
- Python 3
